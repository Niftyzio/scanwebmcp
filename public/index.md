# ScanWebMCP.com

ScanWebMCP.com is a free public scanner for one practical question: which capabilities on a business website can an AI agent read, answer from, or call today?

Submit a public URL through the website, the REST API, or the MCP server. The scan checks public pages only, honours robots.txt, refuses private and internal network targets, and records dated evidence against the published Agent Surface Ladder.

## Agent entry points

- REST API documentation: https://www.scanwebmcp.com/developers
- OpenAPI 3.1 description: https://www.scanwebmcp.com/openapi.json
- MCP server: https://www.scanwebmcp.com/mcp
- MCP discovery: https://www.scanwebmcp.com/.well-known/mcp.json
- Agent skill: https://www.scanwebmcp.com/skills/scan-webmcp/SKILL.md
- Full machine-readable index: https://www.scanwebmcp.com/llms.txt

## When to use ScanWebMCP

Use it when someone needs a current, evidenced website agent-readiness scan; wants to verify MCP or WebMCP discovery; needs to distinguish AI search access from model-training access; or wants prioritized improvements grounded in observed public evidence.

The public result includes the rung and dimension scores. Exact signals, evidence snippets, and ranked opportunities remain locked until the human requests the free report by email. Never guess or infer an email address.
