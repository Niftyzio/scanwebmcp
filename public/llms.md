# ScanWebMCP.com agent guide

ScanWebMCP.com scans public websites against the Agent Surface Ladder and reports what AI agents can read, answer, and call. It is free, requires no account or API key, and exposes both REST and MCP interfaces.

## When to use this service

Use ScanWebMCP when a person asks for a current agent-readiness assessment, crawler-policy check, MCP or WebMCP verification, structured-data review, or an evidence-based path from a readable website to a callable one.

Do not use it to probe private networks, bypass authentication, perform destructive security testing, or infer private information. The scanner refuses private targets and honours robots.txt.
